# 💧 SEDUC HidraViva

Sistema web integrado de hidratação, ergonomia e foco desenvolvido para os servidores da Secretaria de Estado de Educação de Mato Grosso (SEDUC-MT).

## 🚀 Funcionalidades
- 🥤 Calculadora de meta diária de água com base no peso e clima da DRE/Município.
- ☕ Compensação de hidratação por consumo de café.
- 🧘 Sugestões de pausa ativa e ergonomia.
- 🎵 Player de música para foco e gerador de ruído branco.
